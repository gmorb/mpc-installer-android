User manual · app version 1.0.0

MPC Installer
for Android

Install, update and remove VST plugins on a modded Akai MPC or Force from your phone.

Use at your own risk. Plugins from the catalog are community-provided and run as root on your device. They can crash MPC, lose unsaved work or, at worst, leave the device needing a reinstall of its OS. Save your project and back up first. This app is unofficial and not affiliated with or endorsed by Akai Professional.

1. What you need

  • An Android phone or tablet, Android 6.0 or later (the app is built for Android 16 and works on older versions).
  • An Akai MPC OS standalone device that has root SSH access (a modded unit; stock MPC OS does not offer it): Force, MPC Live and Live II, One, X and Key 61. The app refuses a device that is not an MPC OS device.
  • The device's IP address, and its root password if it has one. Your router assigns the address, so look it up on the device (network settings) or in your router each time.
  • The phone and the MPC on the same Wi-Fi network.
  • A card, USB drive or SSD in the MPC, formatted so it can hold symbolic links (ext4 is best). FAT, exFAT and NTFS drives are refused for plugins that need links.

2. Install the app

  1. Download mpc-installer-<version>-android.apk from the project's release page on GitHub, in your phone's browser.
  2. Open the downloaded file. Android asks whether your browser (or Files app) may install apps: allow it for this one install.
  3. Tap Install. If Play Protect shows a scan prompt, choose to scan or install anyway.
  4. Open MPC Installer. The page appears inside the app; there is nothing else to set up.
Updating: install the newer APK over the old one. It only works over an app signed with the same key, so use the APK from the same project release. If Android refuses, uninstall the old app first (nothing about your device is stored in it).

While the app is open it shows a small notification, "MPC Installer is running". That is intentional: it stops Android from cutting the app's Wi-Fi connection when you switch to another app in the middle of a copy.

3. Connect to your MPC

  1. Type the MPC's IP address, for example 192.168.1.50.
  2. Type the root password. Leave it empty only if the device's root has no password. Keys are not used on a phone.
  3. Tap Connect.

The app shows what it found: the device type, the plugin folders already on it, and the places plugins can go. It also shows the device's key fingerprint. If it changes between sessions for the same MPC, be careful: it can mean you are talking to a different device. Nothing about the device is saved on the phone.

4. Choose plugins

The list is the catalog's newest stable release of every downloadable plugin. Use the tabs (Instruments, MIDI, Effects, Addins, All), the search box, the developer filter, the sort and the "show" filter (not on the device, on the device, updates available, only the ones you ticked) to find what you want. Tick the plugins; what you ticked stays ticked while you filter. A bar at the bottom shows the count and an Install button.

You can also add your own release zips with choose zips, which opens the phone's file picker. A zip is checked before it is accepted.

Plugins already on the device are flagged, and so are updates. Catalog downloads are checked against the catalog's checksums before anything is copied; a mismatch installs nothing.

5. Choose where to install

Under Install to the app lists the drives it found under /media that already have a Synths folder, with the free space on each. Pick one. It is chosen for you when there is only one.

No Synths folder yet?

If a card or drive has none, the page lists it with a Create Synths folder button. Tap it and the app makes the folder on that drive, then selects it. Install stays off until a place is chosen; the app never installs somewhere you did not pick.

The internal drive

The internal drive is hidden behind "Use the MPC's internal drive instead (not recommended)". It is the MPC's built-in flash storage (eMMC): every install, update and file a plugin writes adds wear, and if it fails the MPC itself needs repair. A card, USB drive or SSD is cheap to replace. Open that section and tick "I understand" only if you have no other choice.

Notes the app may show

  • Not in MPC's content locations: a plugin's screen may not show until you add the folder in MPC's own settings.
  • Drive not in when MPC starts: its plugins drop out of the plugin list until you register them again (section 8).
  • noexec: Linux can mount a drive with or without permission to run programs, and the same drive can be mounted either way at different times. The app only notes it and still installs. If a plugin shows only "Load Plugin" in MPC afterwards, restart the MPC with the drive in and register the folders.

Under the choices there is a tick box, on by default: after installing, register every plugin folder on the device with MPC. This is built into the app, so nothing has to be on the MPC. It adds missing entries to MPC's plugin list, drops broken ones, and backs up MPC's settings first.

6. Install

  1. Tap Install… and read the summary: what will be installed, where, and how many times MPC restarts (usually once).
  2. Save your project on the MPC first. MPC is stopped and started again, and anything unsaved is lost.
  3. Tap Install. The page scrolls down by itself to the progress area.
  4. Keep the app open until it says "Done. MPC is starting again: the new plugins are in the plugin list."

The app copies every package to a private folder on the device, stops MPC once, runs each plugin's installer, registers the plugin folders, starts MPC once and removes the temporary copies. MPC is started again even if something fails, and nothing after a failing plugin is installed.

If the connection drops

Phones sometimes cut a connection (Wi-Fi sleep, a VPN, switching apps). If it drops during the copy, the app reconnects, checks that the device's key is unchanged, and copies once more. Until every copy has finished, nothing is installed and MPC has not been stopped.

7. Remove plugins

Open 4 Remove plugins (tap Show). It lists the plugin folders on the device. Tick the ones to remove and tap Remove…. The app stops MPC once, backs up MPC's settings, takes the plugin out of the plugin list, deletes the plugin's folder and starts MPC again.

  • Your own files are kept: ROMs, kits and dumps that the plugin's manifest names as user data are not deleted.
  • A plugin the app cannot identify (not from the catalog and not from a zip you added in this session) is listed but cannot be removed from here, because the app cannot tell which files in the folder are yours. Add its release zip to manage it, or remove it by hand.
  • Addins (libraries MPC loads at start-up) are listed last. Removing one runs its own uninstaller, which also takes it out of MPC's start-up list.

8. Something missing from the plugin list?

Installing already registers its plugins, so most people never need this box. Open it (tap Show) when a plugin folder is on the device but MPC does not show it. Typical causes: you copied a folder in by hand, or MPC forgot it because a card was out when it started.

The box shows how many folders are waiting. Tap Register…: the app adds the missing entries, drops entries whose plugin file is gone, leaves everything else alone, backs up MPC's settings first, and restarts MPC once.

9. Clean up old backups

Every install, removal and registering leaves a copy of MPC's settings file (MPC.settings.bak-…) on the device. They are small but nothing deletes them. In 5 Clean up old backups choose how many of the newest to keep (10 is a good number) and tap Delete older backups…. The newest backup is never deleted, and MPC is not restarted.

10. Dark mode and banners

  • Theme: the app follows your phone's light or dark setting. The Theme button forces light, dark or back to automatic. The choice is remembered.
  • Banners: each catalog plugin shows its banner picture in the list. The pictures come from the web, so turn them off with the Banners switch if you are on mobile data. This is remembered too.

11. Troubleshooting

You seeTry this
Connect times outWrong IP, the MPC is asleep, or the phone is on another network (mobile data, guest Wi-Fi). Look the IP up again.
Permission deniedWrong password, or this unit has no root SSH access.
"Not an MPC OS device"The address belongs to another computer. Check the IP.
Install is greyed outNo install location is chosen. Pick a drive, or create a Synths folder on one (section 5).
"software caused connection abort"The phone cut the connection. The app reconnects and retries once by itself. If it still fails, stay in the app, keep the screen on, and try again. Nothing is installed after a failed copy.
Plugin only shows "Load Plugin"Restart the MPC with the drive in, then register the folders (section 8). The drive may have been mounted noexec at that moment.
Plugin screen is emptyThe folder is not one of MPC's content locations, or the plugin has no skin for your MPC OS version (MPC OS 2.x versus 3.x).
Not enough room, or drive refusedFree space on the drive, or use an ext4 drive: FAT, exFAT and NTFS cannot hold symbolic links.
Catalog does not loadThe phone has no internet. The catalog and plugin downloads need it; the MPC does not.
Play Protect blocks the APKUse the APK from the project release (it targets current Android). Choose More details then Install anyway if it still asks.

12. Good to know

  • Nothing about your MPC (address, password) is stored on the phone.
  • Quitting the app while an install is running can leave it half done. The back button asks before quitting.
  • Installing runs a script as root on the MPC and edits MPC's plugin settings; a backup is always made first.
  • The app does not offer device patches (such as the 16-pad drum layout). They change Akai's own program and are not for a phone app. If you want one, run its script over SSH as its own guide says.
  • Developers: build instructions and internals are in tools/android/README.md. The app is the desktop installer (tools/desktop) in an Android wrapper, so the desktop and Android apps share the same page and behaviour.
